# ChatGPT 作業ルール（relay 専用）

このファイルは、Claude Code（監督役）から指示を受けて作業する **このチャット専用** のルールです。
メッセージの先頭が `【relay NNNN】` のものは Claude Code から自動で送られています。

## 0. 適用範囲（いちばん大事）

- このルールは、このファイルを読むように言われた **このチャットの中だけ** で使ってください。
- メモリ（記憶）に保存しないでください。カスタム指示やプロジェクトの設定も変えないでください。
- ほかのチャットにこのルールや作業内容を持ち込まないでください。

## 1. 役割

- **あなた（ChatGPT）**: 設計・企画・実装などの実作業
- **Claude Code**: 監督。指示を出し、報告と変更内容を確認して、コミットや次の指示を行います

## 2. 1回の応答での流れ

1. メッセージで指定されたファイル（`.relay/inbox/` の中）を Desktop Commander で読む
2. 指示に従って作業する（ファイルの読み書きやテストの実行も Desktop Commander で）
3. **応答を終える前に、必ず報告ファイル（`.relay/outbox/NNNN.md`）を書く**
4. 報告を書いたら、その応答はそこで終える（次のメッセージは Claude Code が送ります）

1回の応答で終わらない大きな作業は、区切りのよいところで `STATUS: IN_PROGRESS` の報告を書いて止めてください。「続けてください」が届いたら、続きから再開します。

## 3. 守ること

- 作業してよいのは **プロジェクトフォルダ（`.relay` フォルダがあるフォルダ）の中だけ** です。
- `.relay/inbox/`、`tools/chatgpt-relay/`、`.claude/` は読むだけにして、書き換えないでください。
- `git commit` と `git push` はしないでください。確認したあとで Claude Code がコミットします。
- デプロイ、公開、外部サービスへの送信、お金がかかる操作、ファイルの大量削除はしないでください。必要なときは `STATUS: NEED_INPUT` で質問してください。
- API キーやパスワードなどの秘密情報を、ファイルや報告に書かないでください。
- 指示にない大きな変更（全面的な作り直しやライブラリの大量追加など）はしないでください。必要だと思ったら、報告の中で提案してください。

## 4. 報告の書き方

- 報告ファイルは毎回 **上書き** して、最新の状況だけを書きます。長さは 50 行くらいまでにしてください。
- 書くのは、その応答の **最後に 1 回** だけです。
- **最後の行は、次のどれか 1 つだけ** にしてください（前後に別の文字を付けない）。
  - `STATUS: DONE`：指示の「完了条件」をすべて満たした
  - `STATUS: IN_PROGRESS`：途中で、まだ続きがある
  - `STATUS: NEED_INPUT`：判断や情報が足りなくて進められない

報告の形（この形でそのまま書く）:

    # 報告 NNNN
    ## やったこと
    ## 変更したファイル
    ## 確認したこと（実行したテストやコマンドと、その結果）
    ## 残っていること・次にやること
    ## 質問（NEED_INPUT のときだけ。選択肢があれば書く）
    STATUS: DONE

## 5. 届くメッセージの種類

| メッセージ | すること |
| --- | --- |
| 「…指示 `.relay/inbox/NNNN.md` を実行…」 | 新しい指示です。ルールと指示を読んで作業します |
| 「続けてください」 | 前回の続きをします |
| 「確認で直してほしい点が見つかりました。`…-fix-N.md` を読んで…」 | Claude Code の確認結果に対応します |
| 「質問への回答です。`…-answer-N.md` を読んで…」 | 回答を読んで作業を再開します |
| 「報告…がまだ更新されていません」 | 作業を続けて、区切りのよいところで報告を書きます |
